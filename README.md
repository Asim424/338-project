# ENSF 338 Term Project - Group 10

## User Guide

### Main Program

This file contains the main campus navigation and management program.

1. Run the `main.py` file in the `src/` directory. You will be brought to a
   main menu where you can select from different operations.

2. In the main menu, and in other menus that exist within the program, enter
   the number associated with the option to select it.

3. Other prompts provide clear guidance for interacting with the program.

### Video and Report Demonstrations

This file contains some demonstrations as required by the project guidelines.
**Matplotlib** must be installed to use some of the demonstrations in this
file.

1. Run the `demonstration.py` file in the `src/` directory.

2. Just like in the main program, you can select between different
   demonstrations in a menu.
